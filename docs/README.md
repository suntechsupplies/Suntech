## Organizacao

- `docs/`: documentos detalhados de processos.
- `Fontes/` e `API's HB/`: fontes Protheus; cada documento de processo indica os fontes relacionados.
- `tests/`: testes automatizados; a suite da API HB e descrita em [tests/api_hb/README.md](../tests/api_hb/README.md).
